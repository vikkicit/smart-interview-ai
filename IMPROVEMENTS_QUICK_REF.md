## 🎯 Just 2 Commands to Start

### Command 1: Start Backend
```bash
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8000
```

### Command 2: Start Frontend
```bash
cd frontend
npm install
npm run dev
```

## 🐛 Troubleshooting

**Issue:** No improve button
- Solution: Scroll down in results

**Issue:** Modal doesn't open
- Solution: Check browser console (F12), restart servers

**Issue:** Modal not responsive
- Solution: Check CSS loaded, clear browser cache

**Issue:** Backend error
- Solution: `pip install -r requirements.txt`, restart
